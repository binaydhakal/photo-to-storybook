# Input image provenance

The input is a fictional sample created specifically for this public example with the built-in image-generation tool. It was generated without using an uploaded photograph or any real-person reference. It is an illustrative test input, not a photograph of the repository owner.

The output preview was rendered by Blender using the published `photo-to-storybook==1.0.1` package. Image generation was used only to create the sample input; it was not used to retouch or improve the model preview.

## Final input-image prompt

> Use case: photorealistic-natural. Asset type: fictional sample input photo for a public open-source photo-to-3D Blender example. Create one realistic, entirely fictional adult man, not based on a reference image or a real person. Short side-swept medium brown hair, clean-shaven face, medium warm complexion, clear visible eyes, relaxed slight smile. Wearing a plain sage-green short-sleeved T-shirt, straight light-blue jeans, and charcoal canvas sneakers. Standing naturally with hands in front trouser pockets, facing directly toward the camera. Entire figure visible from hair to shoes, occupying about 88 percent of the frame height; portrait 3:4 composition, centered. Plain warm light-gray seamless studio background, soft even daylight, eye-level camera with minimal perspective distortion, realistic proportions and natural skin texture. No sunglasses, jewelry, graphics, labels, logos, text, watermarks, collage, or border.

## Reproducibility

Use the checked-in `input.png` and `config.json` to reproduce the 3D example. Running the image prompt again may produce a different fictional person and will not recreate the same pixels. The fixed face box in the configuration applies to the supplied image only.

The native model was resaved with relative reference-image and render paths for portability. Its geometry, materials, and preview are unchanged from the generator output.
